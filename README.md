# ERA Downloader – Downloads (Beta)

Aplicativo para analisar um link de vídeo, marcar trechos com precisão e exportar
arquivos prontos para CapCut, DaVinci Resolve e Premiere Pro. Tudo é processado no
seu computador.

## ⬇️ Baixar a versão mais recente

👉 **[Abrir a página de downloads](https://github.com/era-downloader/era-downloader-downloads/releases/latest)**

Na página, em **Assets**, clique no arquivo do seu computador:

| Computador | Arquivo |
|---|---|
| **Mac com chip Apple** (M1, M2, M3, M4, M5…) | `ERA-Downloader_…_macOS-AppleSilicon.dmg` |
| **Windows 10/11** (64 bits) | `ERA-Downloader_…_Windows-x64-setup.exe` |

Não é preciso ter conta no GitHub.

## Primeira abertura

- **Mac:** o app ainda não tem assinatura paga da Apple, então o macOS bloqueia na
  primeira vez. Veja o passo a passo em [GUIA-TESTE-MAC.md](GUIA-TESTE-MAC.md).
- **Windows:** se aparecer "O Windows protegeu o computador", clique em
  **Mais informações › Executar assim mesmo**.

## Versão Beta

Esta é uma versão de testes. Para relatar um problema, use
**Configurações › Sobre › Exportar diagnóstico** no app e envie o arquivo para quem
compartilhou o link com você.
